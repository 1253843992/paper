# ECHO-CIL CWRU 预处理结果

本目录是按类增量实验协议生成的 CWRU 驱动端（DE）数据。原始记录先划分连续块，再切窗，避免同一原始记录的相邻窗口同时出现在训练集和测试集。

## 协议

- 10 类：`N, IR007, OR007@6, B007, IR014, OR014@6, B014, IR021, OR021@6, B021`
- 类增量顺序：基阶段 `[N, IR007, OR007@6, B007]`；增量阶段 1 `[IR014, OR014@6, B014]`；增量阶段 2 `[IR021, OR021@6, B021]`
- 连续块划分：60%/20%/20%，每个切分边界两侧各保护 2048 个原始采样点
- 采样率：12 kHz；窗口长度 2048；训练步长 1024；验证/测试步长 2048
- 归一化：只使用基阶段训练块估计全局均值和标准差，后续阶段固定使用
- 物理特征：500–1500、1500–3000、3000–5500 Hz 三个频带的 Hilbert 包络阶次谱，每个频带 256 个 `0–20` 阶次点；另有 9 个质量特征

## 文件

- `manifest.csv`：每个窗口的来源记录、切分、类别、RPM、原始起止位置和 shard 索引
- `record_inventory.csv`：40 条原始记录的哈希、采样点数、RPM 和连续块边界
- `shards/*.npz`：窗口数组 `x[n,2048]`、阶次谱 `order[n,3,256]`、质量特征 `quality[n,9]`
- `class_mapping.json`：类别编号和任务顺序
- `normalization.json`：固定归一化统计量
- `preprocess_config.json`：完整处理配置
- `summary.json`：窗口数量和质量检查摘要

2 个正常记录没有 RPM 字段，`record_inventory.csv` 和 `manifest.csv` 中以 `rpm_imputed=True` 标记，并使用同一负载下其他记录 RPM 的中位数补齐，仅用于阶次特征计算。
