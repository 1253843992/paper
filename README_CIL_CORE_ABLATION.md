# 核心机制消融

目的：检验机制贡献，而不是要求每个消融都下降。先报告所有组，再按多个种子的配对差值判断。
本轮修复 predict_global 评估 DataLoader 消耗训练全局随机状态的问题：评估使用独立固定种子的 Generator。
不同验证搜索次数不再通过这个路径改变下一阶段初始化；这不是 CUDA 完全确定性的保证。
修复改变了原有随机轨迹，必须在新目录重跑 full，不能与旧基线严格配对。

## 正式运行

```bash
python run_cil_ablation.py \
  --suite core --data echo_cil_processed --order O0 --seeds 0 1 2 \
  --output-root runs/cil_core_replay05 \
  --device cuda:0 --amp --num-workers 4 --cpu-threads 4 \
  --batch-size 128 --epochs 10 --replay-fraction 0.05 --audit-inference
```

13 组、3 种子、3 阶段，完成后主汇总 117 行、四视图诊断 468 行。
`--suite basic` 为原 12 组（默认）；`--suite all` 为去重后的全部组。
`--ablations` 显式指定时覆盖 suite。只运行一个种子可先用 `--seeds 0`，之后相同配置补齐 0 1 2。
`--epochs` 控制基础和增量主训练，预热和巩固仍遵循配置。正式实验不要加 --smoke。

## 对照定义

| 组名 | 干预 | 解释边界 |
|---|---|---|
| full | 完整模型 | 本轮重新训练的参照 |
| no_physical_guidance | 跳过谐波证据编码器及质量门；证据 token 为零、质量系数为 1；关闭证据辅助损失和证据推理融合 | 移除物理条件路径的整体消融，不是单一辅助损失消融；时间/频谱路径保留，原型转速惩罚仍可用 |
| mean_fusion | 跨域注意力替换为归一化证据均值的广播加法；保留后续 FFN 和输出层 | 普通均值残差融合，不是拼接；注意力参数保留但不执行，参数总数不是活跃参数数目 |
| no_spectrum | 不执行频谱编码和残差融合 | 已有结构对照 |
| no_experts | 专家容量上限为 0，不新增低秩专家 | 固定特征维度，类别分类头仍扩展；少了专家预热，训练量并非严格匹配 |
| no_projection | 专家使用空保护基 | 保留专家容量 |
| random_projection | 每阶段替换为随机正交保护基，秩与当阶段可靠关系构造秩相同 | 独立局部随机生成器；因训练轨迹不同，不承诺与 full 每阶段的秩始终相同，应核对记录；不是可靠关系保护，原关系投影误差非零属于预期 |
| no_competition | 新旧类竞争损失权重为 0 | 巩固本来就不使用该损失 |
| no_amplitude | 专家残差幅度损失权重为 0 | 巩固本来就不使用该损失 |
| no_consolidation | 巩固轮数为 0 | 仍存在额外训练量混杂，不可据此证明巩固形式优于等步数训练 |
| no_prototype | 原型融合候选权重仅为 0 | 仍允许验证集选择证据融合 |
| class_mean_prototype | 对保留回放样本的单位特征逐类取均值再归一化，每类一个原型；转速也逐类均值 | 样本访问和回放预算不变；原型数量减少；仍采用相同验证选择流程 |
| no_rpm_penalty | 原型转速惩罚候选仅为 0 | 不删除物理证据编码器中的转速输入 |

四视图审计、结果路径和恢复检查点注意事项见 README_CIL_ABLATION.md。
审计新增 physical_guidance、fusion_mode、lambda_competition、lambda_amplitude；实际专家数量可由 expert_ranks 长度核对。
随机投影类型及构造秩保存在 protection；原型实际数量保存在 results.json 的每阶段记录。
神经分类器视图仍包含网络内部物理分支，不能叫“纯时域模型”。

## 判断顺序

1. 核对实际开关、秩、原型数和完整状态；检查所有种子而非只选最好一次。
2. 配对比较 full 与消融在 fused 和 neural_only 视图的准确率、旧/新类准确率、F1。
3. 若仅融合前下降，说明后处理有补偿；若均无下降，保留“该条件下无独立收益”的结论。
4. 专家、巩固消融同时改变训练预算，应结合 optimizer_steps，后续补严格预算匹配实验。
5. 固定协议后再验证其他类别顺序；不要根据测试集差异反复挑选配置。

本轮尚不包含无回放、无可靠性筛选、等步数巩固替代。无回放会同时改变原型记忆与保护关系的数据来源，
需要单独定义协议；预算匹配也需要控制各阶段早停和更新数，不能简单增加 epochs 冒充匹配。
