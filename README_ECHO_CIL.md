# ECHO-CIL 准确率优化实现

经典类增量对照方法、统一批量运行器和 GPU 命令见 [README_CIL_EXPERIMENTS.md](README_CIL_EXPERIMENTS.md)。

## 小容量回放约束

回放默认且最高为累计已见训练窗口数的10%，向下取整，另受波形序列化字节预算限制。`--replay-fraction` 可降低但不可超过0.1。O0各阶段数量上限为105、186、268；后续训练只能访问上一阶段保留的旧样本和当前新增类别的训练样本，不重新读取被丢弃的旧数据。按类别分配容量、按记录分层选样；字节预算更小时可能少于上述数量。预算不足以每类保留1个样本会明确报错。

原型库仅从阶段结束后保留的回放样本构建，数量不超过回放容量，不保留被丢弃样本的额外特征。`memory_bytes` 统计波形存储，`prototype_tensor_bytes` 单独统计特征库开销，完整模型文件大小另记。10%约束指唯一训练窗口数量，不是每批采样比例，也不是磁盘字节比例；重复采样不增加唯一窗口数。巩固训练同样只用新类数据和有限旧类回放。

结果记录已见训练量、旧类原始训练量、实际回放量、容量上限和比例。旧全量回放结果不能当作本协议结果，必须重新训练。历史阶段输出仅用于审计，不会被自动合并回放。

物理证据均值经LayerNorm进入独立增量分类头，使用权重0.3的辅助交叉熵（与主损失相同的旧/新样本权重）。增量联合训练解冻物理分支及其分类头；预热阶段冻结它们。频谱残差由样本相关sigmoid门控控制；骨干训练时以0.2概率屏蔽整条频谱残差，推理不随机屏蔽。新增参数可通过 `--lambda-evidence`、`--spectral-dropout` 调整。

每阶段先验证选择原型参数，再在验证集选择独立物理分类头的概率融合权重 `--evidence-weights 0 0.1 0.25 0.5`（始终包含0，允许不启用）。此为顺序选择，并非联合全局最优搜索；测试集不参与。`results.json` 记录 `evidence_weight`、`evidence_trials` 和训练日志 `evidence_ce`。新增结构需要从头训练，旧 `stage_2.pt` 不能直接加载为完整新模型；现有预处理数据无需重做。CPU/CUDA与AMP接口不变，CUDA需在服务器验证。

回归检查：`python -m unittest discover -s tests -v`。这些检查验证训练、增量扩展、推理融合和权重保存，不代表准确率提升。

频谱编码器采用双通道：2048点整窗功率谱，以及512点窗口、256点步长的7段平均功率谱。第二通道降低局部瞬态导致的谱估计波动；两个通道分别归一化后联合编码。输入通道变化，需要重新训练，原预处理数据仍可使用。性能提升需正式运行验证。

训练批次按类别和原始记录均衡采样，困难正样本优先选择同类的不同记录。模型和推理参数选择考虑验证集每条记录前后两个时间块的最差准确率；评分为0.4宏准确率+0.4新旧调和准确率+0.2最差块准确率，同分再比较验证交叉熵。每阶段输出 `predictions_stage_*.csv`，包含记录、载荷、RPM、时间位置、预测和前两类概率。融合权重搜索0/0.25/0.5/0.75/1，RPM惩罚包含0；层级权重默认固定0。

验证准确率并列时，以验证交叉熵更低的模型或近邻参数为优先选择，避免100%验证准确率后固定保留最早模型。训练日志记录 `validation_cross_entropy`，近邻搜索记录 `cross_entropy`；近邻数搜索包含1/3/5。

新增原始振动频谱分支（FP32 FFT、相对功率、卷积编码），与时域/包络阶次特征共同融合。训练使用随机循环时间平移，以及权重0.05的批内困难正负样本距离损失。缓存的阶次和质量作为原始视图条件，不随循环平移重新计算。分组学习率按各自初始值同比例余弦衰减。层级参数验证同分时优先选择零权重。

由于模型新增频谱层，需要重新训练；旧检查点不能直接用于这一架构。现有预处理数据可以继续使用。

本实现保留ECHO-CIL的物理特征和正交保护结构，并针对新类学习不足、同故障不同损伤尺寸混淆的问题进行了准确率优先优化。

## 已实现的核心机制

1. 记录内连续区块60/20/20划分，边界两侧各删除一个目标窗口长度；正常记录按48 kHz审计，故障记录按12 kHz审计，再分区块重采样至12 kHz。
2. 2048点时域输入；三频带包络阶次谱、`log(1+S)`、0--20阶256点插值；每窗反射延拓256点。
3. 21个通用谐波查询、4头阶次距离偏置注意力，以及每频带PBR/谱熵/RPM稳定性组成的9维质量向量。
4. 三个由谐波证据和质量门控共同控制的时域尺度块，通道为64/96/128，膨胀率为1/3/7。
5. 时域Query、谐波证据Key/Value的跨域注意力；增量阶段解冻最后一个时域块和融合层，并使用独立的小学习率微调。
6. 可靠旧类边、最大权匹配、分类权重差SVD，以及新增专家残差的FP32前向正交投影。
7. 每个新类建立一个rank=8专家；每阶段最多三个、总数最多六个，使用独立sigmoid门控。
8. 使用归一化余弦分类器，旧分类头冻结，新分类行用类别特征均值初始化。
9. 精确旧/新各半采样，并联合使用竞争间隔、残差幅度、旧类知识蒸馏和监督对比损失。
10. 回放受10%样本数量与32 MiB波形字节双重上限约束，按类别和记录/载荷分层、样本ID哈希确定性选择，并核验实际序列化大小。
11. 每轮验证，以宏平均准确率和新旧调和准确率的均值选择最佳模型，支持早停。
12. 增量阶段结束后仅用新类训练数据与有限旧类回放进行全模型类别均衡巩固，再用更新后的有限回放建立近邻库。验证集选择融合权重与RPM距离惩罚。
13. 长期训练加载器才启用持久worker；逐轮验证与原型提取使用非持久/单进程加载，避免Linux文件描述符耗尽。

## 第一步：重新预处理

主顺序O0：

```bash
python echo_cil_preprocess.py \
  --input CWRU轴承数据/cwru_data \
  --output echo_cil_processed \
  --base-classes 0 1 2 3
```

预处理会生成新的 `normalization.json`。训练程序会拒绝缺少严格物理统计量的旧数据目录。

## 第二步：运行主顺序

GPU：

```bash
python train_echocil.py \
  --data echo_cil_processed \
  --output runs/echo_cil/O0/seed_0 \
  --order O0 \
  --seed 0 \
  --device cuda:0 \
  --amp \
  --num-workers 4
```

CPU验证：

```bash
python train_echocil.py --device cpu --no-amp --num-workers 0
```

默认参数来自 `echo_cil_config.json`：基阶段60轮，新头预热5轮，专家预热3轮，增量联合训练最多60轮，之后进行最多40轮全模型巩固，batch为64。分类头/专家学习率为5e-4，高层主干学习率为1e-5，巩固学习率为1e-4，早停耐心值为10轮。

## 完整5顺序×3种子实验

每个类别顺序需要独立的基阶段归一化统计。批量脚本会自动为每个顺序生成独立处理目录，再运行15个配对实验：

```bash
python run_echo_cil_suite.py \
  --input CWRU轴承数据/cwru_data \
  --processed-root echo_cil_processed_suite \
  --output-root runs/echo_cil_suite \
  --device cuda:0 \
  --num-workers 4
```

## 输出

每个运行目录包含：

- `configuration.json`：实际参数、类别顺序和配置哈希；
- `stage_0.pt`、`stage_1.pt`、`stage_2.pt`：模型、架构元数据和随机状态；
- `memory_stage_*.npy`：默认32 MiB预算内、按类别和记录分层的波形回放；
- `results.json`：阶段精度、AIA、遗忘、BWT、旧新调和均值、可靠边、匹配边、保护秩、投影误差、专家分组、旧类被新类抢占率和资源记录。

`results.json` 是一个对象，阶段结果位于 `stages`，汇总指标位于 `summary`。
